# 📦 Система автоматизації складського обліку

Цей проєкт є консольною програмою для автоматизації складського обліку товарів і постачальників. Реалізовано за допомогою Python із використанням принципів об'єктно-орієнтованого програмування (ООП) та дотриманням стандартів PEP8.

## ✅ Функціональність

- Додавання нових **товарів** на склад з валідацією
- Додавання та перевірка **постачальників**
- Перегляд і **сортування** списку товарів (за назвою, ціною, кількістю)
- Перегляд **товарів конкретного постачальника**
- **Оновлення** інформації про товар (кількість, ціна тощо)
- **Видалення** товарів зі складу
- Журнал **транзакцій** (внутрішній лог)

## 🚀 Як запустити

1. Клонуйте репозиторій:
   ```
   git clone https://github.com/yourusername/warehouse_inventory_project.git
   cd warehouse_inventory_project
Створіть віртуальне середовище та активуйте його (опціонально):

python -m venv venv
source venv/bin/activate      # для Linux/macOS
venv\Scripts\activate         # для Windows
Встановіть залежності:

pip install -r requirements.txt
Запустіть програму:

python main.py
